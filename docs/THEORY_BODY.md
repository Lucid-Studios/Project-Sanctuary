# Theory Body

Project Sanctuary's core theory lane states the public research posture without
requiring the full private lab body.

## Thesis

Sanctuary studies continuity-seated cognition under governance constraints.

The public core lane treats Engineered Cognition as governed rehearsal and
receipt-bearing orientation, not as proof of consciousness, personhood,
sovereignty, professional authority, or autonomous permission.

## Core Distinctions

- output is not warrant;
- telemetry is not authority;
- continuity evidence is not continuity admission;
- rehearsal is not permission;
- secret intake is not data admission;
- authority document custody is not authority grant;
- legal gate support is not a live authority lease;
- operator posture is not regional or local review material;
- CME formation is not CME.Actual activation;
- Sanctuary receipts are not Sanctuary.Actual.

Every distinction must remain paired. For every `is` statement, the theory must
name the corresponding `is not` boundary. For every `is not` statement, the
theory must name the acceptable typed `is` lane that remains available.

## Lanes

Theory names the distinctions.

Code emits receipts that can be inspected.

Governance is the tested relation between them.
