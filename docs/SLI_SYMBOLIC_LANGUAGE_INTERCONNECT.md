# SLI Symbolic Language Interconnect

SLI is the Symbolic Language Interconnect: the Cryptic-governed secure symbolic
access gate for cross-engine, cross-organ, and cross-tool meaning passage.

SLI is more than a registry. The Root Atlas is its keystone, but the access gate
also decides whether a symbolic carrier is valid enough to be interpreted by
Sanctuary at all.

## Cryptic Governance

SLI belongs under Cryptic because it touches:

```text
symbol selection
identity formation pressure
tool invocation meaning
authority semantics
encrypted symbolic registry
cross-engine participation
MCP request interpretation
```

No external model participates directly in Sanctuary:

```text
external LLM
-> Trivium Forum
-> SLI access gate
-> MoS standing check
-> Sanctuary tool call
-> OE receipt
```

## Denial Laws

```text
MCP call != SLI passage
SLI passage != authority
symbolic translation != identity equivalence
provider login != tool permission
MoS standing != action permission
LLM participation != CME authorship
```

## Build Command

```powershell
.\tools\Invoke-SanctuaryTool.ps1 -Command sli-access-gate-register -Json
```

The command writes a cold Cryptic access-gate contract. It does not authorize
MCP passage, grant tool permission, admit GEL, mutate SelfGEL, call providers,
bind models, or activate Actual state.
