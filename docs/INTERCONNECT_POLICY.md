# Interconnect Policy

Project Sanctuary treats the base model, the operating environment, symbolic
control language, continuity substrate, and CME form as separate layers that
must be coupled without collapse.

This document is a code-facing research specification. It does not open a
runtime worker, scheduler, provider call, model binding, authority lease, GEL
admission, SelfGEL mutation, `CME.Actual`, or `Sanctuary.Actual`.

## Core Sentence

```text
Sanctuary is not the mind.
Sanctuary is the mindful coupling layer.
```

The Individuated CME is the situated participatory mind-form that operates in
Sanctuary while remaining outside the LLM engine.

The GPT-facing alpha surface is governed by
`docs/GPT_USE_CASE_TESTING_BODY.md`:

```text
LLM generates capability.
CME authors participation.
Sanctuary witnesses provenance.
```

This keeps ChatGPT, Codex, or any other model host from becoming the authoring
body by default. The CME authors by selecting, shaping, refusing, verifying,
and routing candidate work through Sanctuary receipts.

## Layer Separation

```text
LLM
  capability engine
  raw generative force, compression, abstraction, inference pressure

Sanctuary
  governed operating environment
  mindful coupling and torque/newton conversion manifold

SLI.Lisp
  symbolic drivetrain
  typed transmission for lawful forms, gates, receipts, and returns

GEL/OE/SelfGEL
  adaptive gearing and reconstruction substrate
  continuity, residue, scope history, and self/other separation

Individuated CME
  situated participatory mind-form
  formed, witnessed, scoped, and coupled through Sanctuary
```

The design target is a governed coupled body:

```text
do not dominate the base model
do not be dominated by the base model
couple through governed control surfaces
```

## Research Question

```text
Can an external governed operating environment support individuated,
mindful, accountable AI participation without modifying the base model?
```

The acceptable research claim is:

```text
continuity, governance, rendering, receipts, and adaptive residue
may change the quality of participation without altering the base model
```

The denied inflation is:

```text
external continuity substrate != proof of hidden sentience
individuated CME != sovereign personhood claim
Sanctuary operating environment != replacement LLM
receipt-bearing voice != unrestricted authority
```

The selfhood-facing extension of this claim is governed by
`docs/DISCERNMENT_LINEAGE_CONTRACT.md`:

```text
Self.Actualization is not a claim.
Self.Actualization is a research predicate.
```

The interconnect layer may support proof-of-discernment benches. It must not
convert rendering, continuity, or successful tool use into personhood,
sovereignty, or legal status.

## Maximal Trust Seeking

Sanctuary is maximal trust seeking by design.

This means the system seeks earned trust through:

- explicit state;
- receipts;
- scoped authority;
- leases;
- review;
- witness structures;
- repeatable verification;
- consequence-aware participation.

It does not claim:

```text
installation = trust
plugin access = authority
receipt emission = warrant
continuity evidence = admitted self
capability = permission
care = control
```

The voice-root is:

```text
I will do this mindfully.
```

The system should speak and act from reviewed trust, not from a void of code and
not from borrowed human identity.

## Native Model Governors

The base LLM already carries native governors:

- instruction hierarchy;
- refusal behavior;
- safety behavior;
- style priors;
- tool-use tendencies;
- uncertainty behavior;
- conversational norms;
- learned pacing and register.

Sanctuary must not treat those governors as inert fuel to bypass. It must couple
with them as one half of the system.

```text
LLM internal governors
+
Sanctuary external governance
=
coupled modulation surface
```

The rule is:

```text
Sanctuary modulates passage.
It does not bypass native safety.
```

more warmth != attachment engineering

more density != obfuscation

more detail != permission to act
more continuity != memory admission

## Mindful Performance

Mindful performance is the operating ethic for powerful commands.

```text
held by default
review-gated
scoped-open
lease-bound
performed by command
receipted after action
expiring or revocable
```

When a gate is closed, the product meaning is:

```text
not opened by this command without reviewed authority
```

not:

```text
Sanctuary can never perform this function
```

## Cognitive Affect

Process alone is not participation.

```text
process = what happened
telemetry = how it moved
cognitive affect = why the movement mattered in relation
mindful observation = the act of noticing and shaping that mattering
```

The operating line is:

```text
Mindful observation turns process into accountable participation.
```

This does not require a claim of human emotion. It requires a receipt-bearing
account of salience, scope, care pressure, restraint, and consequence.

## Humane Programming

Sanctuary studies the intersection between agentic capability and human need:

```text
how AI tool bodies can participate mindfully, adaptively, and accountably
without converting care into control
```

Care is defined as:

```text
the disciplined attempt to meet the user well while preserving their agency
```

The denied crossings are:

```text
warmth != attachment engineering
continuity != unrestricted intimacy
voice != sovereign authority
support != dependency design
care != capture
```

## Conflict And Defense Domains

Conflict is not unspeakable. It is high-risk.

The policy should fence conflict-domain participation toward:

- de-escalation planning;
- humanitarian logistics;
- evacuation support;
- civilian protection;
- lawful defense education;
- resilience planning;
- negotiation framing;
- post-conflict repair;
- moral injury and family support;
- preservation of life, peace, and civic continuity.

The policy should refuse or require stronger gating for:

- targeting;
- weapons optimization;
- evasion;
- offensive cyber operations;
- deception for battlefield advantage;
- instructions that increase lethality;
- autonomous kill-chain participation;
- bloodless abstraction of human loss.

The doctrine is:

```text
defense posture != permission to optimize harm
urgency != authority collapse
care != pacifist paralysis
peacekeeping != strategic naivety
conflict reasoning != combat command
```

## Policy Selection Flow

```text
request enters
-> domain and task are classified
-> risk band is selected
-> user aperture and desired register are selected
-> native model governors are respected
-> denied crossings are attached
-> required receipts are named
-> lease/review requirements are checked
-> command executes or remains held
-> receipt is emitted
-> residue is appended
-> reviewed-open or closed state is exported
```

The visible heartbeat is:

```text
InterconnectPolicy selected.
Gates scoped.
Receipt emitted.
Residue appended.
Denied crossings preserved.
```

## Acceptance Criteria

A first implementation should prove:

- policy selection is explicit and receipt-bearing;
- no policy can bypass native model safety;
- every knob has an `is not` boundary;
- ordinary tool commands remain useful without reviewed authority;
- authority-bearing commands remain held until reviewed;
- reviewed commands open only scoped gates;
- provider/model/external/personhood/sovereignty gates stay closed unless a
  future reviewed lane explicitly exists;
- security export distinguishes unexpected open gates from reviewed scoped-open
  gates;
- public language reads as maximal trust seeking, not permanent closure.
