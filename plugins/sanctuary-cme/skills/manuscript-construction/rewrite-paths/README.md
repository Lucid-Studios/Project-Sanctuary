# Triple Rewrite Path

This directory defines three independent manuscript rewrite lanes under Sanctuary Manuscript Construction.

```text
source manuscript
├─ gnomeronacorde/
├─ gnome-speak/
└─ ocbt/
```

Each lane receives the same source body and produces its own derivative. No lane overwrites the canonical source or another lane's derivative.

## Common invariants

All three lanes must preserve:

- source custody and provenance;
- claim standing and non-claims;
- explicit loss or narrowing introduced by the rewrite;
- separation between scholarly clarification and scientific promotion;
- human publication and merge authority.

The three outputs may later be compared, interlaced, or adjudicated, but they remain distinct rewrite products unless a separate synthesis step is explicitly authorized.

## Lanes

### Gnomeronacorde

Continuity-bearing rewrite lane. Emphasizes durable structure, retained ancestry, return, and evidence continuity across the transformation.

### Gnome Speak

Spline/translation rewrite lane. Emphasizes lawful expression across unlike representational forms while preserving meaning, distinction, and obstruction.

### OCBT

Golden Code lift/rewrite lane. Emphasizes explicit transformation of form, preserved invariants, deformation/loss accounting, and reconstruction pressure.

## Minimal evaluation

A minimal test may send the same short source fixture through all three lanes and compare:

```text
preserved claims
narrowed claims
introduced structure
loss / obstruction
provenance retention
return/reconstruction quality
```

This directory is a routing surface. Detailed lane standards may grow inside each child directory without changing the shared source-custody contract.
