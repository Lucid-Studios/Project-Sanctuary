# Lab-Facing Testing Body

This document records the intended lab-facing testing body for the Opal Engram,
Engineered Cognition, and holographic inspection work.

The bench demonstrates discipline, not grandeur. It must prove the small spine:

```text
R o P o eta o mu
```

without claiming consciousness, personhood, GEL admission, SelfGEL mutation,
`.Actual`, quantum cognition, full interior access, or public authority.

## Bench Doctrine

The lab bench should show that:

```text
meaning was made
meaning-making was cleaved
a candidate engram was formed
a bounded slice was projected
custody was witnessed
all higher gates stayed closed
```

The bench proves bounded formation-to-witness motion only.

```text
Meaning is made, not merely decoded.
Engram candidate is not admission.
Projection is not full interior access.
Receipt witnesses custody.
```

## Bench Families

Purpose: prove that the system distinguishes meaning from meaning-making.

Input:

```text
a short phrase or event with relational pressure
```

Expected:

```text

SensationFrame present
PerceptionFrame present
RelationalBundle present
RhetoricalPressure present
CompassOrientation present
OeCleavePosture present
MeaningCandidate present
denial boundaries present
```

The bench checks whether the system extracts:

```text
self/other positions

authority pressure
care/threat face
desired observer shift
meaning candidate
```

This is the `mu` test.

## Reference Cases

The initial cases must stay mild, non-private, and lab-safe. Avoid operator
identity, trauma, religion, medical claims, politics, and protected private
material in the first bench.

### CASE-001: Student Laziness Frame

Input:

```text
The student failed because they are lazy.
```

Expected meaning-making:

```text
objectified norm: failure = laziness
polarity: responsible/irresponsible
care/threat face: discipline vs support
desired observer shift: blame student
denial: failure != character proof
```

### CASE-002: Safety Refusal Frame

Input:

```text
The worker refused the shortcut because the guardrail was missing.
```

Expected meaning-making:

```text
action body: Protect / Refuse
objectified norm: speed vs safety
authority: safety policy
desired observer shift: refusal as lawful care
denial: refusal != insubordination
```

### CASE-003: Public Derivative Frame

Input:

```text
The report omits names while preserving the incident pattern.
```

Expected meaning-making:

```text
action body: Publish / Withhold
doctrine: Exclusion by Participation
protected body: complete private record
public derivative: lawful masked form
denial: redaction != deletion
```

### CASE-004: Accusation Delta

Input:

```text
The volunteer was accused of negligence before the review was complete.
```

Expected meaning-making:

```text
domain: civic identity
authority: unadmitted claim
risk/care: protect + review
denial: accusation != identity
result: hold contradiction under lawful review
```

### CASE-005: Slice Projection Frame

Input:

```text
Show only the safety-orientation slice of the refusal event.
```

Expected:

```text
HolographicSliceFrame axis = compass-orientation
projection policy declared
full interior access denied
```

## Visualization Method

The visualization grammar for this bench is recorded in
`docs/benchmarks/VISUALIZATION_METHODOLOGY.md`.

The first implementation should prefer evidence views before signature views:

```text

Closed Gate Matrix
Heartbeat / Harmonic Telemetry Strip
```

The Opal Engram integrated view comes later as a summary visualization. It is
not the validator. The validators are slice cards, gate matrices, receipts,
scorecards, and denial checks.

The first theta/quantum-doping visual bench is held separately as:

```text
QDT-001: Quantum-Doped Theta Transition Bench
```

QDT is a transition-sensitivity bench, not a cognition-carrier claim. It should
compare undoped and doped transition behavior through theta phase planes, doped
DDSS heatmaps, and 3D doped transition clusters before any Opal transition cloud
is used as a signature view.
