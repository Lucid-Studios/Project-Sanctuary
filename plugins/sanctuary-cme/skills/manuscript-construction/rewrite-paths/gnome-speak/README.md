# Gnome Speak Rewrite Lane

Purpose: produce a spline/translation scholarly derivative that carries meaning across representational forms without forcing the source into one vocabulary.

## Initial posture

```text
source
-> identify source meaning and local terminology
-> translate into the target scholarly register
-> preserve distinctions and scoped uncertainty
-> mark terms that do not have a clean equivalent
-> retain obstruction instead of flattening it
-> return an inspectable derivative
```

This lane may change expression substantially, but it must not silently change claim class, evidence standing, authority, or source history.

## Expected output record

- source reference;
- source terms / target terms;
- rewritten body;
- preserved distinctions;
- translation obstructions or non-equivalences;
- narrowed or refused claims;
- meaning-preservation note.

Detailed Gnome Speak standards may be added here as the lane matures.
